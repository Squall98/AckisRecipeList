# Ackis Recipe List

Addon de suivi des recettes de métiers pour **World of Warcraft 3.3.5a (Wrath of the Lich King)**.
Redistribué pour le serveur **Ebonhold**.

## À quoi ça sert
Ackis Recipe List scanne tes métiers et te dit **quelles recettes il te manque** et **comment les
obtenir** (vendeur, butin, quête, haut fait, réputation…). Idéal pour compléter un métier à 100 %.

## Fonctionnalités
- Scan de **tous tes métiers** (Alchimie, Forge, Couture, Enchantement, Ingénierie, Joaillerie,
  Calligraphie, Travail du cuir, Cuisine, Premiers soins…).
- Liste des recettes **manquantes** avec leur **source** et leur **emplacement**.
- **Filtres** : par source (vendeur / butin / quête…), par niveau de compétence, par réputation requise.
- Intégration avec la carte et les info-bulles.

## Version
- Addon : **v2.01**
- Compatible : WoW **3.3.5a** (build 12340)

## Installation
- **Le plus simple** : via le **launcher Ebonhold** → onglet *Catalogue* → **Installer**.
- **Manuellement** : extraire le dossier `AckisRecipeList` dans `Interface\AddOns\`.

## Utilisation
En jeu : ouvre la fenêtre d'un métier, ou tape la commande `/arl`.
